\# Reverse String



El ejercicio consiste en crear una página web sencilla con lógica JavaScript que invierta el orden de una cadena de texto introducida.



\## Contexto actual

\- Se proporcionan dos ficheros base ``index.html`` y ``script.js``.

\- El contenido inicial de ``index.html`` es el siguente:

```html

<!DOCTYPE html>

<html lang="en">

<head>

&#x20;   <meta charset="UTF-8">

&#x20;   <meta name="viewport" content="width=device-width, initial-scale=1.0">

&#x20;   <title>Reverse String</title>

</head>

<body>

&#x20;   <script src="script.js"></script>

</body>

</html>

```

\- El fichero ``script.js`` no tiene contenido inicial.



\## Restricciones

\- Utilizar JavaScript Vanilla.



\## Resultado esperado

\- Al introducir un texto como, por ejemplo, "AI4Devs" se devuelve "sveD4IA".

\- Los elementos de la interfaz deberán presentar un aspecto redondeado, agradable a la vista.

\- Se deberá mantener la dualidad de ficheros anteriormente definida.
